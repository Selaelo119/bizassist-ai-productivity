🎯 Problem Statement
Business Analysts lose 3+ hours daily on repetitive tasks like drafting emails, summarizing long meetings, and manually planning tasks. This affects productivity
and focus on strategic work.

💡 Solution
BizAssist AI is a browser-based AI productivity assistant that automates 3 core BA tasks using AI-style templates. No installation, no data collection - works offline.

✨ Features
1. Smart Email Generator:** Generates professional emails based on Audience (Client/Manager/Team) and Tone (Formal/Informal/Persuasive).
2. Meeting Summarizer:** Condenses lengthy meeting notes into Summary, Key Decisions, Action Items & Deadlines.
3. Task Planner:** Converts a messy task list into a prioritized weekly plan (High/Medium/Low) with time optimization tips.

🛠️ Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- GitHub Pages for deployment
- Responsive design - works on mobile & desktop

🤖 Responsible AI Statement
This tool uses rule-based AI templates to assist, not replace human judgment.
